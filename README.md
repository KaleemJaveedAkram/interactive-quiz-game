# Quizly — Interactive Quiz Game

A responsive ten-question general knowledge quiz with answer feedback, a timer, a score summary, and a replay flow. Built with vanilla JavaScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds and deploys the app to GitHub Pages when pushed to `main`.
